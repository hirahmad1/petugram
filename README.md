# Petugram — Food Waste → Recipe Generator

**SDG 12: Responsible Consumption and Production**

Enter leftover ingredients. The app generates recipes with Hugging Face **`flax-community/t5-recipe-generation`**, matches a recipe catalog, tracks a digital fridge, and includes food posts + profiles.

## Features

- Leftover ingredient input (chips + free text + voice)
- T5 recipe generation + catalog / web search fallback
- Digital fridge with expiry alerts
- Food posts, follows, and notifications

## Setup

```bash
cd "c:\Users\Dell\Desktop\food waste"
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Put your Hugging Face token in `.env`:

```
HF_TOKEN=hf_...
HF_RECIPE_MODEL=flax-community/t5-recipe-generation
HF_MODEL=sentence-transformers/all-MiniLM-L6-v2
MONGODB_URI=mongodb://localhost:27017
MONGODB_DB=petugram
```

## Run

```bash
.venv\Scripts\activate
uvicorn backend.main:app --reload --host 127.0.0.1 --port 8001
```

Or double-click `start-server.bat`.

Open http://127.0.0.1:8001

## API

`POST /api/match`

```json
{ "ingredients": ["tomato", "egg", "onion"], "top_k": 5 }
```

Recipes are generated by `flax-community/t5-recipe-generation`. Dish names are also supported. If the model is unavailable, the app falls back to catalog matching.

## Security note

If you pasted your HF token in chat, revoke it at https://huggingface.co/settings/tokens and create a new one in `.env`.
